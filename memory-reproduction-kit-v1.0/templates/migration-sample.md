# 长期档案模板（空白，待用户填写）

## L0 · 会话开始时读取的核心

- 用户希望使用的称呼、代词与语言：
- 助手的角色设定与语气偏好（明确标记为设定）：
- 相处方式、沟通偏好与边界：
- 当前最重要的现实项目：
- 当前档案版本和有效日期：

## P · 明确偏好与约定

每条记录包含：ID、内容、适用范围、用户原话、形成日期、来源消息、是否被修正。不要把单次选择自动升级为永久偏好。

## EC · 重要事件卡

每卡包含：ID、标题、现实/虚构分类、时间、人物、背景、起因、经过、结果、情绪与需求的原话、关系或项目意义、后续事项、来源对话ID/消息ID。

## W · 独立虚构世界线

每卡包含：ID、世界线名称、人物、设定、情节、用户修改和后续线索；不写入现实经历。

## 冲突、缺失与待核实

记录矛盾双方、各自日期与来源、当前采用的版本及理由；无依据时保持未决。

## 来源索引

保留原文文件、SHA256、对话/消息/节点ID、分支、原文定位。摘要必须能回到原文。
