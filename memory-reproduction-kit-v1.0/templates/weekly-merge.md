# 每周手动合并指令

请将我指定的日期区间日记和逐消息原文合并进长期档案。先读取当前版本的 migration-sample.md、selected-conversations.md、候选记忆、对应消息JSONL和来源索引；不要以旧缓存覆盖当前文件。

先列日期覆盖与缺失。对话去重使用 conversation_id + node_id；消息ID辅助核对。同一节点内容发生变化时保留版本差异与时间，不静默覆盖。不用正文相似度删除消息，不按时间戳重新打乱父子顺序。不同分支保留父节点及分支身份。只有阅读副本而无稳定ID时，报告无法可靠自动合并，先人工核对。

原始JSON和旧档案保持可恢复。更新阅读档案后核对：去重前后消息数、每段对话消息ID、分支数、跨日归属、修改/缺失条目。migration sample按L0核心、P偏好规则、EC事件卡、W独立世界线、冲突与来源索引分层。重要事件保留背景、经过、结果、用户反馈和原话出处；候选信息不可自动升格成事实。保留人工补充和已有的有效细节。

先生成可审阅的新版本与变更清单，通过核对再替换正式档案。Library文件需更新原身份并处理版本冲突。不要自动删除原始档案。

用户要求更新检索库时，以新版本集合URI导入 cards、passages 和原文，保存写入及读回清单，做核心事实、具体细节和末尾新消息的检索测试。通过后再更改聊天读取指令中的集合URI；保留旧集合以便回退。
