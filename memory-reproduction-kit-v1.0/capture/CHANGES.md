# 0.7.0 · 2026-10-19

- 新增任意显式带时区窗口导出 `chatgpt-sync window` / `chatgpt-window prepare`，支持同日、跨午夜、跨多日和可配置每日分界。
- 按实际窗口结束时间判断覆盖，避免第二个自然日尚未结束时把partial误当作凌晨无消息。
- 源消息ID集合与合并集合核对，保留替代分支、重复节点位置；内容冲突拒绝通过。
- 新增逐消息叙事去向和投递前verify检查；异常使旧成功失效，不完整不得声称完整或投递。
- IANA时区处理夏令时，模糊／不存在的当地分界须提供显式偏移；自然日day和全历史导入仍兼容。
- `aster-diary` 仅为旧本地任务兼容入口，其 --date 默认06:00；通用入口默认00:00或用户指定分界。
