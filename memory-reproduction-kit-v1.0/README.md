# 长期记忆与历史保存复现包 v1.1

请先阅读 [完整教程](长期记忆与历史保存复现教程.md)，再按阶段验收。

1. 填写settings.json，运行scripts/configure.py。
2. 启动capture接收器，在Chrome加载capture/extension，验收手动及自动采集。
3. 转换已有导出、按日提取，手动验收日记后创建本地每日13:00任务；邮件可选。
4. 安装OpenViking0.5.0、CPU嵌入依赖和模型，准备官方插件并通过宿主注册、加载、审核信任。
5. 依据原文整理分层档案，制作带来源片段，导入检索库并验证。
6. 使用明确读取指令；每周手动合并并更新索引。

本包不含个人历史、邮箱、项目ID、凭据或数据库。依赖下载与许可见dependency-sources.json、NOTICE.md。自用后生成的runtime、settings.json、capture/data/state不要公开分享。

本地采集和嵌入不需要付费模型API；日记生成使用自己的助手宿主能力。普通不能访问本机的聊天窗口需要手动上传文件。自动钩子与定时执行必须分别验收，不能因安装成功就视为全部自动化成功。

## v1.1 更新（2026-10-19）

通用修复时间窗改变后的跨日漏收风险：显式带时区start/end、可配置每日分界、跨多日合并、消息ID集合和叙事去向验证。失败不再等同于空集，不完整稿停止投递。默认00:00保持旧设置；可按自己的需要改成06:00等。需重新生成并更新实际每日任务，已有安装不会自动收到修改。

参见[通用时间窗、验证和升级步骤](WINDOWS.md)。`capture/bin/chatgpt-sync window`与`capture/bin/chatgpt-window`均可调用。目录名保留v1.0以兼容已有路径，实际包版本为1.1；旧原文、配置和历史日记不要覆盖。
